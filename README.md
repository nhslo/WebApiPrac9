# Практическая работа 09 — учёт доходов и расходов

## Краткий отчёт

Консольная программа учитывает доходы и расходы в памяти и показывает баланс.

## Выполнение по заданию

### 1. Операции

Структура `Transaction` хранит ID, тип, сумму, категорию и описание. Операции находятся в срезе.

### 2. Меню

Можно добавить доход или расход, посмотреть историю и баланс, вывести расходы по категориям, найти и удалить запись. Для расходов по категориям используется `map`.

### 3. Проверка

При доходе 250 000 и расходе 4 500 баланс равен 245 500 тг. Отрицательная или нулевая сумма, пустая категория и неизвестный ID отклоняются.

## Запуск

Откройте PowerShell в этой папке и выполните:

```powershell
go run .
```

Выбирайте действия цифрами и вводите значения по подсказкам. Данные хранятся до завершения программы.

## Вывод

Баланс получается вычитанием расходов из доходов. Методы с указателем добавляют и удаляют записи.
